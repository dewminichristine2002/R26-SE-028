 1. Project Overview (ElderMeds)
 Title
ElderMeds: A Multimodal Intelligent Assistant for Medication Adherence and Emotional
Well-being Support
 Description (Use this)
ElderMeds is a smart mobile-based system designed to support elderly individuals in managing
their medication routines while also addressing emotional and cognitive challenges such as
loneliness, anxiety, and reduced engagement. The system integrates voice interaction, intelligent
reminders, emotional support, and caregiver insights into a unified platform. By combining
human-centered design and lightweight AI techniques, ElderMeds enhances adherence, improves
emotional well-being, and promotes independent living for aging populations.
 Problem Statement
Elderly individuals often face difficulties in maintaining consistent medication routines due to
cognitive decline, emotional distress, and lack of engagement. Existing systems mainly focus on
reminders but ignore emotional and behavioral factors such as loneliness and anxiety, which
significantly impact adherence.
 Objectives
Main Objective
To develop an intelligent and user-friendly system that improves medication adherence and
emotional engagement among elderly users.
Specific Objectives
• Implement NLP-based conversational interaction
• Provide emotional and cognitive support
• Improve user engagement and motivation
• Ensure ethical, non-intrusive system behavior

 3. MY COMPONENT
This is the most important section.
 3.1 Component Overview
The Emotional & Cognitive Engagement component focuses on identifying and responding to
the emotional state of elderly users through conversational interaction. The system uses Natural
Language Processing (NLP) to analyze user input and detect emotions such as sadness,
loneliness, worry, or happiness. Based on the detected emotional state, the system provides
supportive, non-clinical responses designed to improve engagement, reduce loneliness, and
promote emotional stability.
 3.2 Updated System Flow (IMPORTANT)
User text/voice input
→ NLP processes input
→ Emotion is detected automatically
→ System selects appropriate response
→ Chatbot replies
→ Interaction is stored
 3.3 NLP Design
The system uses lightweight NLP techniques such as text preprocessing and keyword-based
emotion detection. Emotion categories are derived from publicly available datasets such as
Kaggle Emotion Dataset and GoEmotions.
Example:
Input Detected Emotion
“I feel alone today” Loneliness
“I’m worried” Anxiety
“I feel good” Happiness
 3.4 Retrieval-Based Conversational Model
Instead of generating responses using a trained model, the system uses a retrieval-based
conversational approach. Responses are selected from a predefined response bank based on
detected emotional intent. This ensures safety, consistency, and explainability.
 3.5 Response Strategy (IMPORTANT TABLE)
Emotion System Response
Loneliness Reassurance + support
Sadness Comfort + motivation
Worry Calming guidance
Anger De-escalation
Happiness Positive reinforcement

 3.7 Technology Used
• React Native (Frontend)

• Python (Dataset analysis)

 3.8 Why No Deep Learning Model?
A rule-based NLP and retrieval approach was selected instead of a generative model to ensure
ethical safety, avoid incorrect mental health advice, and maintain system explainability.
